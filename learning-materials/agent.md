# Agent（智能体）

## 概念解释
Agent 是指能够自主感知环境、做出决策并执行行动的系统。

## 核心机制
- 感知：接收环境输入
- 决策：分析信息，选择行动
- 执行：采取行动改变环境

## 应用场景
自动驾驶、智能客服、游戏NPC

## 使用边界
Agent 的能力受限于训练数据和计算资源，不能真正理解世界。

## 我的理解
我觉得 Agent 就像一个"能自己干活的助手"。你给它一个目标，它会自己想办法完成，中间不需要你一步步指挥。但它的能力取决于它能看到多少信息（上下文）和它有什么工具（Skill）。
