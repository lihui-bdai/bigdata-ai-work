# Agent、大模型上下文、Skill 三者关系

## 关系说明

| 概念 | 作用 | 相互依赖 |
|------|------|----------|
| 大模型上下文 | 提供信息基础 | Agent 依赖上下文获取环境信息 |
| Agent | 决策和执行主体 | 依赖上下文做判断，调用 Skill 完成任务 |
| Skill | 封装可复用任务 | 被 Agent 调用，减少重复工作 |

## 核心关系

**上下文 → 影响 → Agent 的决策质量**
上下文越完整准确，Agent 做出的判断就越好。

**Agent → 调用 → Skill 来执行具体任务**
Skill 把重复性工作打包，Agent 可以直接使用，不用每次重新学习。

**Skill → 沉淀 → 可复用的任务知识**
Skill 本质上就是把 Agent 做某类任务的经验固化下来，下次直接用。

## 一句话总结

**上下文是 Agent 的"眼睛"，Skill 是 Agent 的"工具箱"。**
