# Skill（技能）

## 概念解释
Skill 是将特定任务的知识和流程打包成可复用的模块。

## 核心机制
- 任务模板：定义输入输出格式
- 知识封装：将领域知识固化
- 可复用性：一次定义，多次调用

## 应用场景
自动生成学习资料、代码审查、报告撰写

## 使用边界
Skill 依赖底层模型的能力，无法超越模型本身的限制。

## 我的理解
Skill 就是把"怎么做某件事"的经验打包成一个模板。这样下次做同样的事，就不用从头再问一遍 AI，直接调用 Skill 就行。
